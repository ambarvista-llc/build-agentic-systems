# build-agentic-systems

Learn to build agentic AI systems by watching one get built: an animation-as-code pipeline that turns sourced briefs into narrated explainer videos, with human review gates. Built in public on YouTube [@AmbarVista](https://www.youtube.com/@AmbarVista).

A casual, learn-by-building project: videos explain concepts as they get implemented here, whenever there's something worth showing.

## Episodes

Episodes are listed here as they're published, each with a link to the code exactly as it was in the video. Episode tags are protected by a GitHub ruleset against deletion and moves.
